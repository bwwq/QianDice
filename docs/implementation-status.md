- 插件宿主已有消息事件、会话回复、持久定时任务、配置和命名空间存储；配置界面支持声明式字符串、数值、枚举和开关字段。
- 部分管理页面仍采用高级JSON编辑；角色创建、牌堆复杂操作以群指令和配置为主。
- 日志导出已改为分页流式输出，管理端提供历史选择与直接保存。
- 群文件上传按用户要求只留插件接口，目前不随附上传服务、不需要域名；未接入时从管理端导出。
- 历史数据库迁移目前仅0→1初始化，未来变更必须加入升级前快照及兼容说明。
